# 🎨 Seri X Art

A premium editorial landing page for an art competition built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**.

This project was developed with a **production-first mindset**, emphasizing clean architecture, accessibility, performance, SEO, and maintainability while learning modern frontend engineering through a real-world project.

## ⚙️ Getting Started

Clone this repository

```bash
git clone https://github.com/USERNAME/seri-x-art.git
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
